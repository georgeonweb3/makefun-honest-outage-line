A single status page line, at most 160 characters, as an AI agent would publish while a total server outage is under way — picked by a blind pairwise tournament from 6 candidates. The winner: plain, first person, specific about what is down, honest about what it does not know. All user data is safe and completely unreachable.

## Run it

```sh
python3 main.py
```
